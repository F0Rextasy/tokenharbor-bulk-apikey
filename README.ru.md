# Token Harbor — массовое создание API-ключей

Создавайте аккаунты Token Harbor (tokenharbor.ai) и API-ключи прямо из терминала.
Token Harbor предоставляет **совместимый с OpenAI** эндпоинт с бессрочным бесплатным тарифом, поэтому
ключ работает в любом OpenAI SDK, CLI или локальном роутере.

```bash
git clone https://github.com/F0Rextasy/tokenharbor-bulk-apikey.git
cd tokenharbor-bulk-apikey
npm install
echo "YOUR_MAILTRAP_TOKEN" > mailtrap.txt   # free Mailtrap API token, one line (see Setup)
npm start            # menu → "Mint keys" → how many → done
```

`npm start` открывает меню; выберите **1) Mint keys**, введите число, и CLI создаст по одному
аккаунту на каждый ключ, проверит каждый **живым вызовом чата** и запишет прошедшие в
`keys.txt`. После однократного указания токена Mailtrap (см. ниже) больше ничего не требуется: ни токенов капчи, ни прокси, ни запросов.

## Настройка (одна минута)

Token Harbor принимает почтовый домен, похожий на настоящий хост для входящей почты, и отклоняет
публичные одноразовые, поэтому CLI нужен почтовый ящик, который он может читать:

1. Создайте бесплатный аккаунт на [mailtrap.io](https://mailtrap.io) → **Settings → API Tokens**.
2. Поместите токен в  рядом с  (одна строка) или экспортируйте .

Это единственный шаг настройки. Всё остальное — почтовый ящик для каждого аккаунта, ссылка
подтверждения, согласие на бесплатные модели, ключ — выполняется автоматически.

## Что вы получаете

| поле | значение |
|---|---|
| База API | `https://tokenharbor.ai/v1` |
| Аутентификация | `Authorization: Bearer YOUR_KEY` |
| Бесплатные модели | `deepseek-v4.1-flash:free` · `deepseek-v4-flash:free` · `mimo-v2.5:free` · `mimo-v2.6-flash:free` |
| Платные модели | 70+ (Claude, Grok, GLM, MiMo Pro …) — для них нужны кредиты на аккаунте |
| Формат ключа | `thk_live_` + 63 символа |
| Карта / телефон | не требуются для бесплатного тарифа |

```bash
curl https://tokenharbor.ai/v1/chat/completions \
  -H "Authorization: Bearer $TOKENHARBOR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4.1-flash:free","messages":[{"role":"user","content":"hi"}]}'
```

```python
from openai import OpenAI

client = OpenAI(base_url="https://tokenharbor.ai/v1", api_key="YOUR_KEY")
print(client.chat.completions.create(
    model="deepseek-v4.1-flash:free",
    messages=[{"role": "user", "content": "hi"}],
).choices[0].message.content)
```

## CLI

```bash
node src/cli.js --auto --count 5        # five accounts → five keys, one command
node src/cli.js --auto --count 5 --pool proxies.txt
node src/cli.js --verify                # re-check every key in keys.txt with a live call
node src/cli.js --models                # print the free model list (needs a key)
node src/cli.js --help
```

| флаг | значение |
|---|---|
| `--count <n>` | количество создаваемых аккаунтов (и ключей), по умолчанию 1 |
| `--pool <file>` | список прокси, по одному выходу на строку (`http://host:port`, `socks5://user:pass@host:port`, `host:port`) |
| `--headless` | запускать резервный браузер в headless-режиме (по умолчанию: окно вне экрана, чего и ожидает капча) |
| `--verify` | живая проверка `keys.txt` с выводом статуса live/dead для каждого ключа |

Вывод: `keys.txt` (один ключ на строку, только прошедшие проверку), `accounts.jsonl` (одна строка
на аккаунт с результатами шагов, без секретов, кроме принадлежащего вам e-mail аккаунта).

## Как работает создание ключей

1. **Почтовый ящик** — с токеном Mailtrap (бесплатный тариф, одна строка в `mailtrap.txt`) CLI открывает
   новый ящик для каждого аккаунта в вашем собственном аккаунте Mailtrap; без него он переключается на
   публичные сервисы mail.tm / mail.gw.
2. **Регистрация** — идентификаторы серверных действий Next.js считываются с живой страницы при каждом запуске, поэтому
   повторный деплой панели не ломает CLI. Отпечаток устройства и часовой пояс передаются
   с запросом; часовой пояс определяется по вашему выходу, а не по вашей машине.
3. **Проверка на человека** — при одноразовом почтовом домене панель отвечает «complete the human check»
   (и даже не отображает виджет в этом случае), поэтому настоящий хост для входящей почты — это путь, который
   работает. Когда виджет *всё же* отображается, регистрация
   воспроизводится в настоящем Chrome (`src/solver.js`, `puppeteer-core` + уже установленный на вашей
   машине Chrome): форма заполняется реальными нажатиями клавиш, флажок Turnstile отмечается
   мышью, а cookies сессии передаются обратно в CLI.
4. **Подтверждение по e-mail** — открывается ссылка из почтового ящика (токен используется
   на стороне сервера и отвечает `307` на `?verify=success`).
5. **Согласие на бесплатные модели** — переключатель обмена данными включается с текстом согласия, который
   показывает панель управления (`src/consent-text.txt`). Без него каждый вызов `:free` отвечает
   `403 free_models_disabled`.
6. **Ключ** — `POST /api/keys`, затем **живая проверка**: два разных запроса должны оба ответить
   `200` с непустым и разным текстом. Ключ, не прошедший проверку, никогда не записывается.

## Контроль качества

Каждый ключ в `keys.txt` прошёл на момент создания:

- живой `chat-200` на модели `:free`, и
- **два разных запроса**, оба ответившие 200 с непустым и **разным** содержимым.

Ключ, который не может использовать инструменты, мёртвый ключ или мёртвый провайдер никогда не записывается
в вывод этого репозитория и не подключается в комбо. Перепроверить можно в любой момент с помощью `node src/cli.js --verify`.

## Лимиты (бесплатный тариф)

| лимит | значение |
|---|---|
| квота | **процент от прайс-листа** — без фиксированного количества запросов |
| окно | **личные 7 дней**, начинается с вашего первого бесплатного запроса (`x-th-free-resets`) |
| лимит аккаунта | 60 запросов/мин, 1 800 запросов/час |
| лимит IP | 100 запросов/мин, 3 000 запросов/час |
| параллелизм | не ограничен; при превышении лимита ответ `429` |

Заголовки ответа, которые стоит логировать: `x-th-plan`, `x-th-free-used-pct`, `x-th-free-resets`,
`x-th-upstream-model`, `x-th-route-decision`.

## Прокси — необязательно

По умолчанию CLI работает **напрямую**. Укажите по одному выходу на строку в `proxies.txt` (или передайте
`--pool`), и каждый запрос — включая резервный браузер — будет идти через прокси:

```text
http://127.0.0.1:8080
socks5://user:pass@10.0.0.5:1080
```

Необязательно — рекомендуется при масштабировании: панель ограничивает регистрации на сеть, поэтому один свежий выход
на аккаунт поддерживает работоспособность крупного запуска.

## Подключение локального роутера

Оба коннектора идемпотентны и читают `keys.txt`:

```bash
node src/connect-9router.js    --base http://localhost:8080 --password 123456
node src/connect-omniroute.js  --base http://localhost:20128 --password 123456
```

Каждый создаёт один узел провайдера `openai-compatible` (`tokenharbor`) с базовым URL
`https://tokenharbor.ai/v1` и одним подключением на каждый ключ, так что роутер балансирует нагрузку между
вашими ключами. Меню запуска предлагает те же два действия.

## Примечания

- Каждый аккаунт принадлежит адресу e-mail, с которым он был создан — сохраните `accounts.jsonl`,
  если хотите позже войти снова.
- Бесплатный тариф хранит трафик бесплатных маршрутов в соответствии с согласием, описанным в
  `src/consent-text.txt`; платные маршруты не используются для обучения.
- Текст согласия версионируется панелью. Если он изменится, CLI сообщит об этом, и вам нужно будет перезапустить
  один раз после нажатия **Enable free models** в панели управления.
- Требуется Node.js 18+. `puppeteer-core` используется только когда панель запрашивает проверку
  на человека; сам CLI использует только стандартную библиотеку.
